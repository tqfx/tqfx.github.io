a_real w,
a_point2 * res )

evaluate a point on the line at a given parameter.

Let a line be defined by origin point \(\vec{o}\) with direction vector \(\vec{v}\) (where \(\|\vec{v}\| = 1\)). The point \(\vec{p}\) on the line at parameter \(w\) is given by:

\[ \vec{p}=\vec{o}+\vec{v}w \]

Parameters
[in]ctxpoints to an instance of the two-dimensional line
[in]wis the scalar parameter
[out]resstores the result

◆ a_line2_parm()

a_real a_line2_parm ( a_line2 const * ctx,
a_point2 const * rhs )

compute the scalar projection parameter of a point onto the infinite line.

Let \(\vec{p}\) be a point and let a line be defined by origin point \(\vec{o}\) with direction vector \(\vec{v}\) (where \(\|\vec{v}\| = 1\)). The scalar projection \(w'\) of vector \((\vec{p}-\vec{o})\) onto the line is given by:

\[ w'=\frac{(\vec{p}-\vec{o})\cdot\vec{v}}{\|\vec{v}\|}=(\vec{p}-\vec{o})\cdot\vec{v} \]

Parameters
[in]ctxpoints to an instance of the two-dimensional line
[in]rhspoints to the point to project
Returns
the scalar parameter

◆ a_line2_proj()

a_real a_line2_proj ( a_line2 const * ctx,
a_point2 const * rhs,
a_point2 * res )

project a point onto the infinite line.

Let \(\vec{p}\) be a point and let a line be defined by origin point \(\vec{o}\) with direction vector \(\vec{v}\) (where \(\|\vec{v}\| = 1\)). The projection \(\vec{p}'\) of point \(\vec{p}\) onto the line is given by:

\begin{aligned} \vec{p}'&=\vec{o}+\frac{\vec{v}}{\|\vec{v}\|}\frac{(\vec{p}-\vec{o})\cdot\vec{v}}{\|\vec{v}\|} \\&=\vec{o}+\vec{v}\left[(\vec{p}-\vec{o})\cdot\vec{v}\right] \end{aligned}

Parameters
[in]ctxpoints to an instance of the two-dimensional line
[in]rhspoints to the point to project
[in]resstores the projection result
Returns
the projection parameter
